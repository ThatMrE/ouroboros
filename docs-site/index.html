Repair Continuum — Study Methods & Analysis

Reference index for the N-of-1 pilot's pre-registration, statistical analysis plan, data infrastructure, device-QA protocol, and analysis code. Methods and code only.

Unofficial working reference. Not medical advice; not a solicitation. Dosing parameters, route, and administration are out of scope here and require a licensed physician and a sterile-compounding pharmacy. Any second human subject (Cohort 2) requires IRB review.

  • Pod-output bench test
    Gravimetric delivery-accuracy QA per IEC 60601-2-24 (benign fluid, bench only)
  • OSF registration form
